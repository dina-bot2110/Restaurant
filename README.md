# Restaurant Management System (MS Access)

## 📌 Project Overview
A comprehensive database system built using **Microsoft Access** for a restaurant to manage orders, meals, customers, and employees. This project was developed as a team project during my second year at the Faculty of Computers and Information, Assiut University.

## 👥 Team Size & Role
- **Team of 5 students.**
- **My Role:** 
  - Designed and created key database tables (e.g., Customers, Orders, Meals).
  - Populated the database tables with sample data.
  - Collaborated with a teammate to write and test complex SQL Queries for data retrieval.

## 🛠️ Tools Used
- Microsoft Access (Tables, Queries, Forms, Reports)

## 🚀 How to Run
1. Download the `.accdb` file from this repository.
2. Open it using Microsoft Access 2016 or later.
